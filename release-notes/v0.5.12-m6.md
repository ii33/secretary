# 秘书办公室 v0.5.12-m6

DSH 的「项目记忆 + 控制台」插件。把 ES（秘书）与用户的对话流水沉淀成项目长期记忆，按冷热分层管理，并提供一个可操作的控制台。

## 记忆核心（Python，纯标准库）

- **持久层**：SQLite。表覆盖 `turns` / `notes` / `taskboard` / `conventions` / `advice` / `summaries` / `brief` / `cold_index` / `raw_event` / `audit` / `artifact` / `role_policy`。
- **中文检索**：FTS5 contentless 虚表 + bigram 分词（NFKC 归一化 → 双字切分 → 英文词），结果按「覆盖度 0.62 + 时间衰减 0.20 + 重要度 0.10」重排，返回高亮片段。单字查询自动退回 LIKE。
- **冷热分层**：`hot_raw` → `processed` → `cold` 状态机。冷层原文落到独立文件，检索可跨层（`scope=all`）。
- **压缩**：纯规则梳理器，四类保守提取（决策 / 完成项 / 偏好 / 待决问题），不调 LLM，重复执行幂等。
- **回收站**：归档 → 回收 → 恢复 → 彻底清除；`purge` 连带清理冷层文件。
- **两个入口**：本地 HTTP REST（`/v1/*`）+ 17 个命令的 CLI 逃生口（`serve` / `doctor` / `ingest` / `search` / `get` / `recent` / `brief` / `note` / `stats` / `export` / `backup` / `compress` / `archive` / `recycle` / `restore` / `purge` / `init`）。

## 控制台（DSH 插件）

- 顶部项目下拉 + 6 个标签页：**记忆管理 / 项目预设 / 人员架构 / 顾问建议 / 任务板 / 项目约定**。
- 记忆管理内含 5 个子标签：简报 / 搜索 / 最近 / 压缩 / 归档·回收站。
- 人员架构按 `es·顾问 → gm → dm → worker` 树状展示，可折叠；显示自定义名（默认「预设名+序号」）、会话标题、预设；已归档与空会话自动过滤。
- 任务板三列（长期目标 / 阶段目标 / 当前任务），项目约定两列（避免 / 遵守），列表项可新增、移除、挂起、激活。
- 项目预设支持从全局导入、导出到全局；自定义预设默认不进全局。

## 分流规则

| 对话 | 去向 |
|---|---|
| ES ↔ 用户 | 热记忆（自动收录，可手动压缩） |
| ES ↔ GM | 冷备（原始记录） |
| GM ↔ DM ↔ worker、顾问、普通会话 | 不收录 |
